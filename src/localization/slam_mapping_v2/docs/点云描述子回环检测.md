# CSC 回环检测模块设计方案

## Context

当前 `slam_mapping_v2` 已有基于 KD-Tree 空间邻近 + GICP 精配准的激光回环检测器（`KdtreeGicpLoopDetector`）和视觉 ORB+DBoW2 回环检测器（`VisualLoopDetector`），两者均实现 `ILoopDetector` 接口并通过工厂创建。

`relocalization` 包中已有完整的 CSC（Cylindrical Scan Context）描述子实现，可作为算法参考。但为避免包间耦合，**将 CSC 描述子算法内部化实现到 `slam_mapping_v2` 中**，类型适配为 `slam_mapping_v2` 自有的 `Pose` / `PointType`。

**目标**：在 `slam_mapping_v2` 内部实现完整的 CSC 描述子回环检测流程：「CSC 描述子粗匹配 → GICP 精配准 → 回环验证 → 添加约束」，不依赖 `relocalization` 包。

**约束**：不引入任何外部包依赖，所有代码在 `slam_mapping_v2` 内部实现。

---

## 架构设计总览

```
┌──────────────────────────────────────────────────────────────────────┐
│                         slam_mapping_v2                               │
│                                                                       │
│  LoopDetectorFactory                                                  │
│    └─ "csc" → CscLoopDetector : ILoopDetector                         │
│         │                                                             │
│         ├─ CscDescriptor (内部实现)                    ← 描述子粗匹配  │
│         │    ├─ makeDescriptor(cloud) → Matrix                        │
│         │    ├─ add(kf_id, pose, desc)                 增量构建       │
│         │    └─ query(desc, top_k) → CscCandidate[]                   │
│         │                                                             │
│         └─ IFineRegistrar (接口)                       ← 精配准解耦    │
│              └─ GicpFineRegistrar : IFineRegistrar                     │
│                   ├─ buildSubmap(kfs, idx)                            │
│                   └─ align(src, tgt, init_guess) → FineResult         │
│                                                                       │
│  MappingRuntime                                                       │
│    └─ detector_->detect(keyframes_) → LoopCandidate                   │
│         └─ optimizer_.addLoopFactor(candidate)                        │
└──────────────────────────────────────────────────────────────────────┘

依赖关系（零外部包依赖）：
  CscLoopDetector ──uses────→ CscDescriptor     (slam_mapping_v2 内部)
  CscLoopDetector ──uses────→ IFineRegistrar    (slam_mapping_v2 内部)
  GicpFineRegistrar ──uses──→ PCL ICP with Normals (已有依赖)
  CscDescriptor   ──uses───→ Eigen + PCL PointXYZI (已有依赖)
```

## 模块详细设计

### 模块 1：CSC 描述子内部实现

**新增文件**：
- `slam_mapping_v2/include/slam_mapping_v2/core/csc_descriptor.hpp`
- `slam_mapping_v2/src/core/csc_descriptor.cpp`

**设计原则**：
- 算法逻辑参考 `relocalization/src/descriptor/csc_descriptor.cpp`
- 所有类型使用 `slam_mapping_v2` 自有类型（`Pose`、`PointType`）
- 不引入 `relocalization` 的任何头文件
- 点云内部使用 `pcl::PointXYZI`（CSC 算法需要），对外接口使用 `slam_mapping_v2::PointCloudPtr`

**头文件设计**：

```cpp
// csc_descriptor.hpp
#pragma once

/**
 * @file csc_descriptor.hpp
 * @brief CSC（Cylindrical Scan Context）描述子 — slam_mapping_v2 内部实现
 *
 * 4 通道圆柱描述子：max_range / point_density(对数归一化) / mean_intensity / max_z
 * 两阶段检索：RingKey 粗筛 + 扇区旋转对齐精排
 * 增量构建：逐关键帧 add()，查询时自动使用已添加的条目
 */

#include "slam_mapping_v2/common/types.hpp"

#include <Eigen/Dense>
#include <pcl/point_cloud.h>
#include <pcl/point_types.h>

#include <string>
#include <vector>

namespace slam_mapping_v2 {

// ── CSC 配置参数 ──────────────────────────────────────────────────────
struct CscConfig {
  int num_sectors = 60;              ///< 扇区数（yaw 方向分辨率）
  int num_height_bins = 16;          ///< 高度层数（z 方向分辨率）
  double min_height = -1000.0;       ///< 最低高度
  double max_height = 15.0;          ///< 最高高度
  int num_channels = 4;              ///< 通道数（max_range, density, intensity, max_z）
  double max_radius = 100.0;         ///< 最大径向距离
  double min_range = 3.0;            ///< 最小径向距离（过滤近处噪声）
  double ground_threshold = -1000.0; ///< 地面高度阈值
  std::vector<double> channel_weights = {0.6, 0.5, 0.2, 0.3}; ///< 通道权重
  std::string similarity = "l1";     ///< 相似度模式："l1" | "balanced"
  int ring_key_candidates = 300;     ///< RingKey 粗筛候选数
};

// ── CSC 数据库条目 ────────────────────────────────────────────────────
struct CscEntry {
  int keyframe_id = -1;
  double timestamp = 0.0;
  Eigen::Vector3d position = Eigen::Vector3d::Zero();
  Eigen::Quaterniond orientation = Eigen::Quaterniond::Identity();
  Eigen::MatrixXd descriptor;        ///< 形状: (n_bins * n_channels, n_sectors)
  Eigen::VectorXd ring_key;          ///< RingKey 向量（旋转不变）
  Eigen::VectorXd sector_key;        ///< SectorKey 向量
};

// ── CSC 候选结果 ──────────────────────────────────────────────────────
struct CscCandidate {
  int keyframe_id = -1;
  double score = 1e9;                ///< 描述子相似度得分（越小越相似）
  double ring_dist = 1e9;            ///< RingKey 粗筛距离
  int sector_shift = 0;              ///< 最佳扇区偏移量
  double yaw_diff = 0.0;             ///< 估计的 yaw 角差异（弧度）
  Eigen::Vector3d position = Eigen::Vector3d::Zero();
  Eigen::Quaterniond orientation = Eigen::Quaterniond::Identity();
};

// ── CSC 描述子核心类 ──────────────────────────────────────────────────
class CscDescriptor {
 public:
  explicit CscDescriptor(const CscConfig& config = CscConfig());

  const CscConfig& config() const { return config_; }
  const std::vector<CscEntry>& entries() const { return entries_; }

  /// 从点云构建 CSC 描述子矩阵（输入 pcl::PointXYZI 点云）
  Eigen::MatrixXd makeDescriptor(
      const pcl::PointCloud<pcl::PointXYZI>::ConstPtr& cloud) const;

  /// 从 slam_mapping_v2 点云构建描述子（内部转换 PointXYZINormal → PointXYZI）
  Eigen::MatrixXd makeDescriptorFromMappingCloud(const PointCloudPtr& cloud) const;

  /// 增量添加条目到数据库
  void add(int keyframe_id, double timestamp,
           const Eigen::Vector3d& position,
           const Eigen::Quaterniond& orientation,
           const Eigen::MatrixXd& descriptor);

  /// 清空数据库
  void clear();

  /// 查询与输入描述子最相似的 top_k 个候选
  std::vector<CscCandidate> query(const Eigen::MatrixXd& descriptor, int top_k) const;

  /// 数据库条目数
  std::size_t size() const { return entries_.size(); }

  /// 摘要信息
  std::string summary() const;

 private:
  /// 构建 RingKey（高度-通道均值向量，排除强度通道，旋转不变）
  Eigen::VectorXd makeRingKey(const Eigen::MatrixXd& descriptor) const;

  /// 构建 SectorKey（扇区均值向量）
  Eigen::VectorXd makeSectorKey(const Eigen::MatrixXd& descriptor) const;

  /// 计算最佳描述子相似度得分（遍历所有扇区偏移）
  double bestDescriptorScore(const Eigen::MatrixXd& query,
                              const Eigen::MatrixXd& candidate,
                              int* best_shift) const;

  CscConfig config_;
  std::vector<CscEntry> entries_;
};

}  // namespace slam_mapping_v2
```

**实现要点**（`csc_descriptor.cpp`）：

- 算法逻辑从 `relocalization/src/descriptor/csc_descriptor.cpp` 移植
- `makeDescriptorFromMappingCloud()`：将 `PointXYZINormal` 转换为 `PointXYZI`，提取 intensity 字段
- `add()`：构建 `CscEntry` 并计算 RingKey/SectorKey，追加到 `entries_`
- `query()`：两阶段检索 — RingKey L2 粗筛 → `bestDescriptorScore` 精排
- `bestDescriptorScore()`：遍历所有扇区偏移，计算加权 L1 或 balanced 余弦距离
- 不依赖 `relocalization` 的任何类型，所有类型在 `slam_mapping_v2` 命名空间内

**点云转换**（在 `makeDescriptorFromMappingCloud` 内部）：

```cpp
Eigen::MatrixXd CscDescriptor::makeDescriptorFromMappingCloud(
    const PointCloudPtr& cloud) const {
  // PointXYZINormal → PointXYZI 转换
  auto xyzI = pcl::PointCloud<pcl::PointXYZI>::Ptr(new pcl::PointCloud<pcl::PointXYZI>());
  if (cloud) {
    xyzI->reserve(cloud->size());
    for (const auto& pt : cloud->points) {
      if (!std::isfinite(pt.x)) continue;
      pcl::PointXYZI p;
      p.x = pt.x; p.y = pt.y; p.z = pt.z;
      p.intensity = pt.intensity;
      xyzI->push_back(p);
    }
  }
  return makeDescriptor(xyzI);
}
```

### 模块 2：精配准接口抽象（IFineRegistrar）

**新增文件**：
- `slam_mapping_v2/include/slam_mapping_v2/core/i_fine_registrar.hpp`

**设计**：

```cpp
#pragma once

#include "slam_mapping_v2/common/types.hpp"

#include <Eigen/Dense>
#include <string>

namespace slam_mapping_v2 {

/// 精配准结果
struct FineRegistrationResult {
  bool success = false;
  bool converged = false;
  double fitness = 1e9;           ///< ICP fitness score
  double inlier_ratio = 0.0;     ///< 内点比例
  double inlier_rmse = 1e9;      ///< 内点 RMSE
  int inlier_count = 0;
  int correspondence_count = 0;
  Eigen::Matrix4d transform = Eigen::Matrix4d::Identity();
  PointCloudPtr aligned;         ///< 配准后的源点云
  PointCloudPtr target;          ///< 目标点云
};

/// 精配准抽象接口（解耦具体算法：GICP / VGICP / NDT 等）
class IFineRegistrar {
 public:
  virtual ~IFineRegistrar() = default;

  virtual void configure(const LoopClosureConfig& cfg) = 0;
  virtual void reset() = 0;

  /// 对源点云与目标子图执行精配准
  /// @param source      源点云（当前关键帧，map 系）
  /// @param target      目标子图（历史关键帧邻域，map 系）
  /// @param init_guess  初始变换猜测（来自描述子 yaw_diff + 位姿差）
  /// @return 精配准结果
  virtual FineRegistrationResult align(
      const PointCloudPtr& source,
      const PointCloudPtr& target,
      const Eigen::Matrix4d& init_guess) const = 0;

  virtual std::string summary() const = 0;
};

}  // namespace slam_mapping_v2
```

**设计要点**：
- 纯接口类，不依赖任何具体配准算法
- `configure()` 接收 `LoopClosureConfig`，复用已有配置结构
- `align()` 输入输出明确：源点云 + 目标子图 + 初始猜测 → 配准结果
- `FineRegistrationResult` 包含完整的质量指标，供调用方做回环验证
- 未来可扩展 NDT、VICP 等实现，仅需新增实现类

### 模块 4：CSC 回环检测器（CscLoopDetector）

**新增文件**：
- `slam_mapping_v2/include/slam_mapping_v2/core/csc_loop_detector.hpp`
- `slam_mapping_v2/src/core/csc_loop_detector.cpp`

**设计**：

```cpp
// csc_loop_detector.hpp
#pragma once

#include "slam_mapping_v2/core/i_loop_detector.hpp"
#include "slam_mapping_v2/core/i_fine_registrar.hpp"
#include "slam_mapping_v2/core/csc_descriptor.hpp"

#include <memory>
#include <vector>

namespace slam_mapping_v2 {

/// CSC 回环配置（嵌入 LoopClosureConfig）
struct CscLoopConfig {
  // 描述子参数
  int num_sectors = 60;
  int num_height_bins = 16;
  double max_radius = 100.0;
  double min_range = 3.0;
  double ground_threshold = -1000.0;
  std::vector<double> channel_weights = {0.6, 0.5, 0.2, 0.3};
  std::string similarity = "l1";
  int ring_key_candidates = 300;

  // 检索参数
  int top_k_candidates = 5;        ///< 描述子检索返回的候选数
  double csc_score_thresh = 0.5;   ///< CSC 描述子得分阈值（越小越相似）

  // 精配准验证
  double fine_fitness_thresh = 0.3;
  double fine_inlier_ratio_thresh = 0.3;
  double fine_inlier_rmse_thresh = 0.5;
};

class CscLoopDetector : public ILoopDetector {
 public:
  CscLoopDetector();

  void configure(const LoopClosureConfig& cfg) override;
  void reset() override;
  LoopCandidate detect(const std::vector<Keyframe>& kfs) override;
  const std::vector<std::pair<int, int>>& loopPairs() const override { return loop_history_; }
  PointCloudPtr latestCurrentSubmap() const override { return latest_current_submap_; }
  PointCloudPtr latestHistorySubmap() const override { return latest_history_submap_; }

  /// 注入精配准器（依赖注入，解耦具体算法）
  void setFineRegistrar(std::unique_ptr<IFineRegistrar> registrar);

 private:
  /// 判断是否应该执行回环检测
  bool shouldCheck(const std::vector<Keyframe>& kfs, int current_idx) const;

  /// 从关键帧增量构建描述子并加入数据库
  void addKeyframeDescriptor(const std::vector<Keyframe>& kfs, int kf_idx);

  /// CSC 粗匹配：描述子检索
  std::vector<CscCandidate> coarseMatch(const Eigen::MatrixXd& query_desc) const;

  /// 精配准验证
  bool fineRegistration(const std::vector<Keyframe>& kfs,
                        int current_idx,
                        const CscCandidate& candidate,
                        FineRegistrationResult* result) const;

  /// 从精配准结果构建 LoopCandidate
  LoopCandidate buildLoopCandidate(const std::vector<Keyframe>& kfs,
                                    int current_idx, int history_idx,
                                    const FineRegistrationResult& result) const;

  LoopClosureConfig cfg_;
  CscLoopConfig csc_cfg_;

  // CSC 描述子（内部实现，不依赖外部包）
  std::unique_ptr<CscDescriptor> descriptor_;

  // 精配准器（依赖注入）
  std::unique_ptr<IFineRegistrar> registrar_;

  // 状态
  int last_loop_check_index_ = -1;
  int last_added_index_ = -1;       ///< 最后一个已添加描述子的关键帧索引
  std::vector<std::pair<int, int>> loop_history_;

  // 可视化
  PointCloudPtr latest_current_submap_;
  PointCloudPtr latest_history_submap_;
};

}  // namespace slam_mapping_v2
```

**detect() 流程**：

```
detect(keyframes):
  1. current_idx = keyframes.size() - 1
  2. shouldCheck() → 检查索引间隔、时间间隔
  3. 增量构建描述子：
     for i in (last_added_index+1 .. current_idx):
       addKeyframeDescriptor(keyframes, i)
  4. 构建当前关键帧描述子
     query_desc = descriptor_->makeDescriptorFromMappingCloud(keyframes[current_idx].cloud)
  5. CSC 粗匹配：
     candidates = descriptor_->query(query_desc, top_k_candidates)
     if candidates.empty() → return invalid
  6. 对每个候选执行精配准验证：
     for candidate in candidates:
       if fineRegistration(keyframes, current_idx, candidate, &result):
         return buildLoopCandidate(keyframes, current_idx, candidate.keyframe_id, result)
  7. return invalid
```

**addKeyframeDescriptor() 流程**：

```
addKeyframeDescriptor(kfs, kf_idx):
  // 转换点云并构建描述子
  desc = descriptor_->makeDescriptorFromMappingCloud(kfs[kf_idx].cloud)
  // 增量添加到数据库
  descriptor_->add(kfs[kf_idx].id,
                    kfs[kf_idx].timestamp,
                    kfs[kf_idx].pose_map.position,
                    kfs[kf_idx].pose_map.orientation,
                    desc)
```

**fineRegistration() 流程**：

```
fineRegistration(kfs, current_idx, candidate, result):
  1. 构建源子图（当前关键帧，search_num=0）
     source = GicpFineRegistrar::buildSubmap(kfs, current_idx, 0, resolution)
  2. 构建目标子图（历史关键帧邻域）
     target = GicpFineRegistrar::buildSubmap(kfs, candidate.keyframe_id, search_num, resolution)
  3. 构建初始猜测：
     - 从 candidate.yaw_diff 获取旋转校正
     - 从两个关键帧 pose_map 获取位姿差
     - T_cur = poseToMatrix(kfs[current_idx].pose_map)
     - T_hist = poseToMatrix(kfs[candidate.keyframe_idx].pose_map)
     - yaw_correction = Eigen::AngleAxisd(candidate.yaw_diff, Vec3d::UnitZ())
     - init_guess = T_hist^-1 * T_cur * yaw_correction.matrix()
  4. registrar_->align(source, target, init_guess)
  5. 验证结果：
     - result.converged == true
     - result.fitness <= csc_cfg_.fine_fitness_thresh
     - result.inlier_ratio >= csc_cfg_.fine_inlier_ratio_thresh
     - result.inlier_rmse <= csc_cfg_.fine_inlier_rmse_thresh
  6. 若通过验证，计算 diff_rot / diff_pos（与 KdtreeGicpLoopDetector 一致）
```

**buildLoopCandidate()**：

```
buildLoopCandidate(kfs, current_idx, history_idx, result):
  // 从 ICP 变换计算回环约束（与现有 KdtreeGicpLoopDetector 逻辑一致）
  T_hist_cur = result.transform
  r_pre = kfs[history_idx].pose_map.orientation.toRotationMatrix()
  r_cur = kfs[current_idx].pose_map.orientation.toRotationMatrix()
  diff_rot = r_pre^T * T_hist_cur.block<3,3>(0,0) * r_cur
  diff_pos = r_pre^T * (T_hist_cur.block<3,3>(0,0) * cur_pos + T_hist_cur.block<3,1>(0,3) - pre_pos)

  return LoopCandidate{
    valid: true,
    history_idx: history_idx,
    current_idx: current_idx,
    score: result.fitness,
    diff_rot: diff_rot,
    diff_pos: diff_pos
  }
```

## 解耦分析

| 维度 | 解耦方式 |
|------|---------|
| **外部包依赖** | **零外部包依赖**，CSC 描述子在 `slam_mapping_v2` 内部实现 |
| **描述子解耦** | `CscDescriptor` 是独立类，可被任何模块使用，不绑定检测器 |
| **精配准解耦** | `IFineRegistrar` 接口抽象，`CscLoopDetector` 不知道具体用 GICP/VGICP/NDT |
| **工厂解耦** | `LoopDetectorFactory` 通过字符串 "csc" 创建，调用方无需知道实现类 |
| **配置解耦** | `CscLoopConfig` 嵌套在 `LoopClosureConfig` 中，YAML 驱动 |
| **ROS 解耦** | 核心逻辑在 `core/` 层，ROS 仅在 `config_loader` 和 `node` 层 |
| **点云类型** | CSC 内部使用 `PointXYZI`（算法需要），通过 `makeDescriptorFromMappingCloud()` 封装转换 |

## YAML 配置示例

```yaml
loop_closure:
  enable: true
  detector_type: "csc"           # 使用 CSC 描述子回环检测

  # 通用回环参数
  min_index_gap: 20
  time_thresh_sec: 20.0
  loop_kf_gap: 30
  max_range: 20.0
  submap_search_num: 25
  submap_resolution: 0.3

  # CSC 描述子参数
  csc:
    num_sectors: 60              # 扇区数（yaw 分辨率）
    num_height_bins: 16          # 高度层数
    max_radius: 100.0            # 最大径向距离
    min_range: 3.0               # 最小径向距离
    ground_threshold: -1000.0    # 地面高度阈值
    channel_weights: [0.6, 0.5, 0.2, 0.3]  # 通道权重
    similarity: "l1"             # 相似度模式："l1" | "balanced"
    ring_key_candidates: 300     # RingKey 粗筛候选数
    top_k_candidates: 5          # 描述子检索返回候选数
    csc_score_thresh: 0.5        # CSC 得分阈值

    # 精配准验证参数
    fine_fitness_thresh: 0.3
    fine_inlier_ratio_thresh: 0.3
    fine_inlier_rmse_thresh: 0.5
    fine_registrar_type: "gicp"  # 精配准器类型："gicp"

  # 位姿图噪声参数
  loop_noise_scale: 1.0
  loop_rot_noise: 0.05
  loop_pos_noise: 0.5
  loop_score_floor: 0.05
```

## 与 relocalization 的关系

本方案 **仅参考** `relocalization` 包中 CSC 描述子的算法实现，但：
- **不添加** `relocalization` 作为 CMake/package 依赖
- **不引用** `relocalization` 的任何头文件
- **不修改** `relocalization` 的任何文件
- CSC 描述子代码在 `slam_mapping_v2` 内部独立实现，类型完全适配 `slam_mapping_v2` 自有类型
- 未来两个包的 CSC 实现可以独立演进，互不影响
