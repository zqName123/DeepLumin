# 视觉回环集成测试方案

> **版本**: v1.0
> **模块**: slam_mapping_v2 / VisualLoopClosure
> **日期**: 2026-08-25

---

## 一、概述

本文档描述 slam_mapping_v2 视觉回环检测功能的集成测试方案。视觉回环基于 ORB 特征 + DBoW2 词袋检索，作为激光回环的补充/替代方案。

### 1.1 测试目标

1. 验证视觉回环检测功能的基本正确性
2. 验证与现有激光建图流程的兼容性
3. 验证回环可视化（rviz marker）的正确显示
4. 验证位姿图优化在视觉回环约束下的效果

### 1.2 前置条件

- 已完成代码集成（config_loader、mapping_runtime、node）
- 已准备包含图像话题的 rosbag 数据
- 已确认相机内参（fx, fy, cx, cy）

## 二、配置说明

### 2.1 启用视觉回环

修改 `config/slam_mapping_v2.yaml`：

```yaml
loop_closure:
  enable: true
  detector_type: "visual"  # 改为 "visual" 或 "hybrid"
```

### 2.2 视觉配置参数

```yaml
loop_closure:
  visual:
    # 词库路径（必须）
    vocabulary_path: "/path/to/ORBvoc.txt"

    # ORB 特征参数
    nfeatures: 2000        # 每帧最大特征点数
    scale_factor: 1.2      # 图像金字塔缩放因子
    nlevels: 8             # 金字塔层数
    ini_th_fast: 20        # FAST 角点初始阈值
    min_th_fast: 7         # FAST 角点最小阈值

    # BoW 检索参数
    min_bow_score: 0.03    # 最小 BoW 相似度分数
    min_shared_words: 20   # 最小共享单词数
    max_candidates: 3      # 最大候选帧数

    # 特征匹配参数
    min_bow_matches: 50    # 最小匹配点数
    nn_ratio: 0.6          # Lowe's ratio test 阈值

    # RANSAC 几何验证参数
    ransac_min_inliers: 15     # 最小内点数
    ransac_probability: 0.99   # RANSAC 置信度
    ransac_max_iterations: 300 # 最大迭代次数

    # 连续性验证参数
    min_continuity: 3          # 连续确认帧数
    max_continuity_miss: 2     # 最大丢失帧数

    # 相机内参（必须根据实际标定修改）
    camera:
      fx: 500.0
      fy: 500.0
      cx: 320.0
      cy: 240.0
    # LiDAR 到相机的外参 T_L_C（4x4 齐次变换矩阵，行优先）
    # 默认值适用于典型矿车安装配置
    T_L_C: [0., 0., 1., 0.30456,
           -1., 0., 0., 0.00065,
            0.,-1., 0., 0.65376,
            0., 0., 0., 1.]
```

### 2.3 图像话题配置

```yaml
input:
  image_topic: "/camera/image_raw"  # 修改为实际图像话题
```

## 三、测试流程

### 3.1 Step 1：确认 rosbag 数据

```bash
# 查看 rosbag 信息
rosbag info your_data.bag

# 确认包含以下话题：
# - /camera/image_raw (sensor_msgs/Image)
# - /localization/slam_odom (nav_msgs/Odometry)
# - /localization/cloud_registered (sensor_msgs/PointCloud2)
```

### 3.2 Step 2：修改配置

1. 修改 `detector_type: "visual"`
2. 修改 `image_topic` 为实际话题名
3. 修改相机内参（camera.fx/fy/cx/cy）
4. 确认 `vocabulary_path` 路径正确
5. 确认 LiDAR-相机外参（T_L_C）正确

### 2.4 外参配置说明

`T_L_C` 是 LiDAR 到相机的 4x4 齐次变换矩阵，行优先存储：

```
T_L_C = [R_L_C | t_L_C]
        [  0  |   1  ]
```

其中：
- `R_L_C`：3x3 旋转矩阵，将点从相机坐标系变换到 LiDAR 坐标系
- `t_L_C`：3x1 平移向量，相机原点在 LiDAR 坐标系下的坐标

**默认值适用于典型矿车安装配置**：
- 相机 x 轴 = LiDAR z 轴（相机朝前 = LiDAR 朝上）
- 相机 y 轴 = -LiDAR x 轴
- 相机 z 轴 = -LiDAR y 轴
- 平移偏移：[0.30456, 0.00065, 0.65376] 米

**如果相机安装位置不同，需要重新标定外参。**

## 四、预期结果

### 4.1 正常情况

| 指标 | 预期 |
|------|------|
| 视觉特征提取 | 每帧提取 ~2000 个 ORB 特征点 |
| 回环检测 | 在重复场景区域检测到回环 |
| 可视化 | rviz 中显示橙色球体和绿色连线 |
| 位姿图优化 | 轨迹在回环处发生明显修正 |

### 4.2 异常情况

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无特征提取 | 图像话题无数据 | 检查 image_topic 配置和 rosbag |
| 特征点过少 | 图像质量差/纹理少 | 调整 nfeatures 或 ini_th_fast |
| 无回环检测 | 场景无重复/参数过严 | 降低 min_bow_score 或 min_continuity |
| 误检回环 | 参数过松 | 提高 min_bow_score 或 ransac_min_inliers |
| 优化效果差 | 相机内参不准 | 重新标定相机 |

## 五、参数调优建议

### 5.1 提高召回率（检测到更多回环）

```yaml
visual:
  min_bow_score: 0.02      # 降低 BoW 分数阈值
  min_shared_words: 15     # 降低共享单词数要求
  min_bow_matches: 30      # 降低匹配点数要求
  min_continuity: 2        # 降低连续确认帧数
```

### 5.2 提高精确率（减少误检）

```yaml
visual:
  min_bow_score: 0.05      # 提高 BoW 分数阈值
  min_shared_words: 30     # 提高共享单词数要求
  min_bow_matches: 80      # 提高匹配点数要求
  ransac_min_inliers: 20   # 提高内点数要求
  min_continuity: 4        # 提高连续确认帧数
```

### 5.3 提高性能

```yaml
visual:
  nfeatures: 1000          # 减少特征点数
  buffer_size: 50          # 减少缓冲区大小
```

## 七、附录

### 7.1 激光 vs 视觉回环对比

| 维度 | 激光回环 | 视觉回环 |
|------|----------|----------|
| 检测方法 | KD树 + GICP | BoW + RANSAC |
| 适用场景 | 几何特征丰富 | 纹理丰富 |
| 尺度 | 有绝对尺度 | 需从 odom 恢复 |
| 精度 | 高（毫米级） | 中（厘米级） |
| 计算量 | 中 | 低 |

### 7.2 混合模式

当 `detector_type: "hybrid"` 时，激光和视觉回环并行运行，任一检测到回环即触发优化。适用于场景复杂、单一传感器可能失效的情况。
